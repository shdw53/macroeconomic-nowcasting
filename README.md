## Тема проекта

**Тема проекта:** Прогнозирование макроэкономических показателей в реальном времени с использованием пространственных и текстовых данных и временных рядов.<br>
**Трек:** ML-трек

### Проблематика и ценность

Официальная государственная статистика по макроэкономическим показателям публикуется с колоссальной задержкой от 2 месяцев до года. Наш проект решает проблему информационной асимметрии. Мы создаем нейеросетевую модель, которая оценивает текущее состояние экономики «здесь и сейчас», что представляет огромную бизнес-ценность для федерального реального сектора, банков и девелоперов.
