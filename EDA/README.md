# Датасет для nowcasting ВРП регионов

Выгрузка сделана 24.10.2026. Значения взяты из источников без правок. Признаки, полученные преобразованием (ряд из нарастающего итога, среднее за месяц по дневному ряду, доля раздела в ВРП), отмечены в каталоге в колонке `transform`.

## Источники

ЕМИСС: Росстат, ФНС, ВВП<br>
Банк России: кредиты, ипотека, вклады, ставка, курс, мониторинг, кривая бескупонной доходности ОФЗ<br>
World Bank: мировые цены на нефть, индексы <br>
Консультант Плюс: производственный календарь<br>
geoBoundaries: соседство и расстояния между регионами<br>


## Где что лежит

`data/raw/<источник>/` хранит сырые файлы с сайта источника. В `data/interim/` лежат неотфильтрованные таблицы. Признаки собраны в `data/processed/`:

| Файл | Что внутри |
|---|---|
| `features_regional_monthly_long.parquet` / `_wide` | 119 признаков, регион x месяц  |
| `features_regional_annual_long.parquet` / `_wide` | 62 признака, регион x год |
| `features_national_monthly_long.parquet` / `_wide` | 126 общих для всех регионов факторов, месяц |
| `features_national_annual_long.parquet` | рост ВВП России за год |
| `target_grp_long.parquet` / `_wide` | ИФО ВРП по разделам - это таргет |
| `feature_catalog.csv` | по каждому признаку группа и этап, единицы, частота, описание, преобразование, ID показателя, URL, время выгрузки, первый и последний период, число регионов |
| `coverage_matrix_regional_monthly.csv` | матрица «регион x признак», где записано число месяцев со значением |

Широкие таблицы (`_wide`) содержат только регионы выборки, длинные содержат все единицы, у которых есть `region_id`, включая РФ и федеральные округа.

В `data/reference/` лежат `regions.csv` (справочник регионов), `adjacency_long.csv` (пары регионов, общая граница, расстояние между центроидами, км) и `region_geo.csv` (центроид, площадь, число соседей региона).

## Выборка регионов

В выборке 85 субъектов (флаг `in_sample` нужен для того, чтобы отфильтровать строки с значениями в целом по РФ и федеральным округам). ДНР, ЛНР, Запорожская и Херсонская области исключены за недостатком данных. Крым и Севастополь в выборке, их ряды начинаются с 2014–2015 годов.

Справочник регионов построен по классификатору ОКАТО из ЕМИСС (показатель 57806).

## Особенности данных, которые важны для модели

Значения оставлены такими, как их публикует источник, включая резкие выбросы.

Ряды по ОКВЭД1 и ОКВЭД2 не склеены. По ИПП они перекрываются в 2015–2016 годах.

Остатки Банка России на первое число месяца отнесены к концу предыдущего месяца.

У Крыма и Севастополя нет границ в geoBoundaries, поэтому в матрице соседства их нет. Калининградская и Сахалинская области соседей по суше не имеют.

Национальные ряды взяты из строк РФ. С 2023 года Росстат даёт ВВП, ИПЦ, ИПП и розницу по «Российской Федерации без учета новых субъектов». Где эта строка есть, в датасете стоит она, а до 2023 года стоит строка «Российская Федерация».
